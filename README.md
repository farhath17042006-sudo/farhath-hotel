# Farhath Food Order

A premium, fast, and authentic food ordering website rebuilt in pure HTML5, CSS3, and Vanilla JavaScript. 

This project aims to deliver a high-quality restaurant browsing and ordering experience without relying on heavy frameworks. It features a fully functioning front-end shopping cart, category filtering, and a modern responsive design.

## Features

- **Beautiful Responsive UI**: Designed with a premium color palette (Burgundy & Charcoal) mimicking top-tier dining apps.
- **Dynamic Food Menu**: Categorized tabs (Pizza, Burgers, Drinks, Desserts, Other Food) that dynamically filter the menu using JavaScript.
- **High-Quality Accurate Imagery**: Every food item uses a specific, matching high-resolution image. No generic placeholders.
- **Fully Functional Cart System**: 
  - Add items to your cart directly from the menu.
  - Slide-out right panel showing all cart contents.
  - Increment, decrement, or remove items.
  - Live total price calculation.
- **Offline Capable**: No complicated backend or build steps are required. All logic runs in the browser.

## How to Run

Because this project is built using vanilla web technologies, you can run it instantly:

1. **Simple Method**: Double click the `index.html` file in your file explorer. It will open in your default browser.
2. **Developer Method**: 
   - Open this folder in **VS Code**.
   - Install the **Live Server** extension if you haven't already.
   - Right-click on `index.html` and select **"Open with Live Server"**.

## Technologies Used

- **HTML5**: Semantic layout and structure.
- **CSS3**: Variables, Flexbox, Grid, animations, hover states, and responsive media queries.
- **Vanilla JavaScript**: State management (`cart` array), filtering logic, mathematical calculations, and dynamic DOM injection.
- **FontAwesome**: For lightweight, crisp scalable icons.
- **Google Fonts**: Inter (sans-serif) and Playfair Display (serif).
